# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。

## 离线包合并与签署版本

厂家回站离线包（`离线包合并`页）按“采集时间 + 缺陷修订号 + 校验和”接收：

- 相同包号或校验和的重复包只入库一次；校验和与内容不符整包拒收（内置重复包、篡改包、新包三个示例）。
- 每份包逐条拆成合并任务：修订号新于站内可直接并入；新增条目随包建单；引用的设备/验收项缺失则“合并失败”，依赖补齐后可从失败项重试，已成功的回复和证据不受影响。
- 同一缺陷站内与离线包两边都动过时，两版均保留并列出责任方、证据和复测编号，人工裁决当前判定；厂家复测只进入待联合复验，**缺陷关闭仍以站内复测结论为唯一依据**。
- 证书有效期、验收项状态或未关闭缺陷发生变化时，当前有效签署版本立即失效、电站退回“待复核”，重新检查后方可签署新版本；历史版本的签署依据与失效原因完整留存。
- 审计可按设备、缺陷、修订号、离线包、类别过滤；缺陷详情沿站内/厂家修订号时间线呈现每次判定。

业务数据在浏览器 localStorage 持久化（带 schema 版本），刷新或重开页面判定可追溯。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
